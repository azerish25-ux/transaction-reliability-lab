# ADR-002 — Database owns spending authority

Status: SQL written, not runtime-verified.

## Decision
Runtime commands invoke restricted SECURITY DEFINER functions. Keep ledger/hold/balance/audit/outbox/idempotency changes in one PostgreSQL transaction, with commit-time invariants and stable lock order.

## Consequences and alternatives
A Java mutex cannot protect multiple API/worker instances. Direct runtime table writes would bypass business rules. Stored procedures increase SQL review/migration complexity and repeated reconciliation has an unmeasured cost. Owner/superuser compromise is outside this restricted-runtime boundary.
