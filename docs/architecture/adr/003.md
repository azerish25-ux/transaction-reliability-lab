# ADR-003 — Durable idempotency and unknown outcomes

Status: SQL/JDBC source and client component behavior; database behavior unverified.

## Decision
Claim actor/kind/parent/key and canonical intent in the same transaction as the effect/outcome. Retry only controlled transaction-abort SQLSTATEs. Preserve uncertainty after response loss and keyed 5xx/408; retry original identity.

## Consequences and alternatives
A client timeout cannot establish rollback. Replaying a fresh key could duplicate accepted money. The design avoids in-memory-only locks/cache and retains deterministic outcomes. General replay retention/archival and the actual endpoint for unresolved-intent lookup are still missing.
