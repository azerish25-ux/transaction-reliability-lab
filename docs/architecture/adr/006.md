# ADR-006 — Evidence scopes and physical lab separation

Status: Component laboratory implemented/executed; normal release package absent.

## Decision
Use separate lab-support source mutations with baseline/mutant/restoration evidence and explicit UNIT_COMPONENT_ONLY scope. Preserve raw assertions and source hashes. Exclude lab-support from main Java source paths.

## Consequences and alternatives
A Boolean fault flag in the normal application would enlarge the threat surface. A changed helper test is not proof of a full-system defect; G07 stays unmet. Directory separation alone is not an artifact/runtime isolation proof: release package and network control-surface tests must still run.
