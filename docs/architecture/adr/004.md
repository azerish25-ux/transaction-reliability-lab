# ADR-004 — Reservations and compensating entries

Status: Pure state/hold policies unit-verified; stored operations unexecuted.

## Decision
PENDING acceptance reserves available funds without changing posted money. Settlement consumes the reservation; cancel/fail releases it. Refund/reversal creates a new opposite journal, never rewrites history.

## Consequences and alternatives
Holding on acceptance prevents oversubscription but requires careful release/consume state consistency. Recipient refunds check both refundable amount and available funds. Full admin reversal after a partial refund is rejected. Restart/cancel/settle/refund races still require real database tests.
