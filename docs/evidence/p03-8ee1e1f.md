## Meaningful oracles

`P0309` copies an authenticated cookie, verifies it on the other API process, logs out, rejects the copied cookie, restarts that process and rejects the copy again. A new valid login still works. `P0306` drives ten signed-token variants through actual protected HTTP routes. `P0307` checks altered role bytes and unsigned tokens. `P0315` checks direct and nested cross-customer resource access.

`P0317` performs actual protected funding/transfer posting and verifies only the owner's entries/economic effect appear through HTTP, with independently recomputed ledger balances. `P0320` repeats account commands without refreshing CSRF on every request and checks stable owner-only pagination. `P0324` tests restricted-role denial of direct protected mutations and irreversible revocation. `P0327` preserves a real V5 historical user/account through V6, but is not the full later financial-history/backup-restore campaign.

The fourteen scoped requirements and concrete test-ID prefixes are maintained in [P03_REQUIREMENTS.json](../implementation/P03_REQUIREMENTS.json). The follow-on evidence checker derives the per-candidate matrix from executed case names, rather than treating planned IDs as completed coverage.
