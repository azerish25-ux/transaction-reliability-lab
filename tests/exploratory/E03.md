# E03 — Identity and privilege boundaries

Status: PREPARED, NOT EXECUTED. Risks: R10, R11, R12.

## Mission
Find discrepancies between visible navigation and server-side ownership/role enforcement.

## Setup and entry criteria
Distinct Alice/Bob/admin sessions in isolated contexts; owned/nested resource identifiers; expired and tampered test tokens only, never real user tokens. The real integrated environment and approved lab controls must first be available; do not substitute mock pages.

## Suggested session scope
One bounded 45-minute exploration session with one primary question; stop immediately on suspected unexplained financial corruption and preserve state. This is a future charter, not an execution log.

## Techniques and heuristics
Try guessed direct and nested IDs, role mass assignment, payer-initiated recipient refund, admin spending, invalid/missing CSRF, logout/reuse, wrong JWT audience/issuer and altered claims. Verify denied reads cannot disclose balances/history.

## Observations and evidence
Capture sanitized requests, safe problem codes, absence of financial effects and security-event correlation. Record only redacted token structure. Store actual session records under `docs/evidence/exploratory/E03/` only after execution, with source SHA, environment, tester type, start/end times and artifact hashes.

## Debrief
Did a UI-hidden function remain callable? Were ownership filters applied at query time? Did failure messages disclose unrelated account data? Separate observations from hypotheses and automated evidence from human judgments.
